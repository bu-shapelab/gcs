# Rendering a Design

1. Open `render.blend` in Blender.

2. Switch to the **Scripting** workspace.

3. In the Text Editor, select the saved `Load Geometry` script from the text dropdown.

4. Set the desired design ID:

    ```python
    design = 5
    ```

5. Run the script by pressing the **Run Script** button or `Alt + P`.

6. Render the scene by pressing `F12` or selecting:

    ```text
    Render → Render Image
    ```

7. After the render finishes, save it using:

    ```text
    Image → Save As...
    ```
